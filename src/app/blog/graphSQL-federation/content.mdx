GraphQL Federation solves the monolithic schema problem by enabling distributed GraphQL architectures. Instead of one massive schema, federation composes multiple service schemas into a unified graph, enabling true microservices scalability.

## The Federation Architecture

Federation introduces the concept of a supergraph - a composed schema from multiple subgraphs. The Apollo Gateway acts as a query planner, intelligently routing requests across services.

<CodeWindow title="Gateway Configuration">

```javascript
import { ApolloGateway, IntrospectAndCompose } from "@apollo/gateway";
import { ApolloServer } from "apollo-server-express";

const gateway = new ApolloGateway({
  supergraphSdl: new IntrospectAndCompose({
    subgraphs: [
      { name: "users", url: "http://users-service:4001/graphql" },
      { name: "products", url: "http://products-service:4002/graphql" },
      { name: "orders", url: "http://orders-service:4003/graphql" },
      { name: "reviews", url: "http://reviews-service:4004/graphql" },
    ],
  }),
  debug: false,
  queryPlannerConfig: {
    // Advanced query optimization
    reuseQueryFragments: true,
    incrementalDelivery: {
      enableDefer: true,
    },
  },
});

const server = new ApolloServer({
  gateway,
  subscriptions: false,
  plugins: [
    // Custom plugins for monitoring and caching
    require("./plugins/monitoring"),
    require("./plugins/distributed-cache"),
  ],
});
```

## Advanced Resolver Implementation

Federated resolvers handle cross-service data fetching with sophisticated patterns:

<CodeWindow title="Federated Resolvers">

```javascript
// users-service resolvers
const resolvers = {
  User: {
    // Entity resolver - called by gateway
    __resolveReference: async (user, { dataSources }) => {
      return dataSources.userAPI.getUserById(user.id);
    },

    profile: async (user, args, { dataSources }) => {
      // Lazy load profile data
      return dataSources.userAPI.getUserProfile(user.id);
    },
  },

  Query: {
    user: async (_, { id }, { dataSources }) => {
      return dataSources.userAPI.getUserById(id);
    },

    users: async (_, { limit }, { dataSources }) => {
      return dataSources.userAPI.getUsers({ limit });
    },
  },
};

// orders-service resolvers
const resolvers = {
  User: {
    // Extend User type from another service
    __resolveReference: async (user) => {
      return { __typename: "User", id: user.id };
    },

    orders: async (user, { status }, { dataSources }) => {
      return dataSources.orderAPI.getOrdersByUserId(user.id, { status });
    },

    totalSpent: async (user, args, { dataSources, redisCache }) => {
      // Cache expensive calculations
      const cacheKey = `user:${user.id}:totalSpent`;
      let total = await redisCache.get(cacheKey);

      if (!total) {
        total = await dataSources.orderAPI.calculateTotalSpent(user.id);
        await redisCache.setex(cacheKey, 3600, total); // 1 hour cache
      }

      return parseFloat(total);
    },
  },

  Order: {
    __resolveReference: async (order, { dataSources }) => {
      return dataSources.orderAPI.getOrderById(order.id);
    },
  },
};
```

## Distributed Caching Strategy

Implement sophisticated caching across the federated architecture:

<CodeWindow title="Distributed Cache Implementation">

```javascript
class FederatedCachePlugin {
  requestDidStart() {
    return {
      willSendResponse: async (requestContext) => {
        const { response, request, cache } = requestContext;

        // Cache based on query complexity and data sensitivity
        if (this.shouldCache(request.query)) {
          const cacheKey = this.generateCacheKey(request);
          const ttl = this.calculateTTL(request.query);

          await cache.set(cacheKey, response.data, { ttl });
        }
      },

      didResolveSource: async (requestContext) => {
        // Implement field-level caching
        const fieldCacheKey = this.getFieldCacheKey(
          requestContext.source,
          requestContext.info
        );

        const cachedResult = await requestContext.cache.get(fieldCacheKey);
        if (cachedResult) {
          return cachedResult;
        }
      },
    };
  }

  shouldCache(query) {
    // Smart caching decisions based on query analysis
    const complexity = this.calculateComplexity(query);
    const hasPersonalData = this.containsPersonalData(query);

    return complexity > 50 && !hasPersonalData;
  }
}
```

## Performance Monitoring

Monitor federated performance across all services:

<CodeWindow title="Federation Monitoring">

```javascript
const federationMetrics = {
  queryPlanCache: new Map(),
  serviceLatency: new Map(),

  recordQueryPlan: (query, plan) => {
    const planHash = hash(plan);
    federationMetrics.queryPlanCache.set(query, {
      planHash,
      serviceCount: plan.node.service.length,
      estimatedCost: plan.node.estimatedCost,
    });
  },

  recordServiceLatency: (serviceName, latency) => {
    if (!federationMetrics.serviceLatency.has(serviceName)) {
      federationMetrics.serviceLatency.set(serviceName, []);
    }

    const latencies = federationMetrics.serviceLatency.get(serviceName);
    latencies.push({ timestamp: Date.now(), latency });

    // Keep only last 1000 measurements
    if (latencies.length > 1000) {
      latencies.shift();
    }
  },
};
```
